# Código de conduta

Este espaço é para melhorar o token-guard. Trate quem contribui com respeito, critique o código e não a pessoa, e aceite que
um pedido recusado com motivo faz parte do trabalho. Assédio, insulto e exposição de dados pessoais não têm lugar aqui.

Quem presenciar ou sofrer isso pode avisar o mantenedor pelo canal de segurança descrito em `SECURITY.md`. O mantenedor pode
remover comentários, issues e contribuições que violem este código e vetar quem insistir.
