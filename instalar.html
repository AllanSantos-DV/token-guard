instalação

Três comandos. Sem npm install.

01npx @allansantos-dev/token-guard audit
02npx @allansantos-dev/token-guard init --target all
03npx @allansantos-dev/token-guard test

Alvos: copilot · claude · codex · cursor · mcp · repo (viaja no git). Emergência: TOKEN_GUARD=off.

Depois, npx @allansantos-dev/token-guard setup abre a tela de configurações.
